What the policy id is for

The policy id is the hash of this entire offer — merchant, price, resource, expiry. Your payment commits to it on chain, in a block only your key can sign. Nobody can afterwards claim the price was different, and nobody can claim you paid when you did not: there is no "grant" switch on the server to flip, only blocks anyone can re-check.

Your wallet

Merchant: configure what you accept

Choose the token, set the prices, publish the offer. The offer's id is the hash of these fields, so changing any of them later is a different offer — not a re-priced one.
